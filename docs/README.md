# Documentation

This directory is for detailed documentation that doesn't belong in CLAUDE.md.

## What goes here

- Detailed architecture explanations
- Training method deep-dives
- Research notes and paper summaries
- API documentation
- Tutorials and guides

## What goes in CLAUDE.md

Only essential quick-reference info:
- Project overview (brief)
- Common commands
- Key file locations
- Critical configuration

## What goes in code

- Module docstrings with usage examples
- Config file comments explaining options
- Inline comments for complex logic
